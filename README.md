# Pedestrian Detection Project

This project detects pedestrians in images or video streams using C++ and OpenCV.

## Structure
- `src/` : Source code
- `CMakeLists.txt` : Build configuration

## Requirements
- OpenCV (>=4.x)

## Build
```
mkdir build
cd build
cmake ..
make
```

## Run
```
./PedestrianDetection <input_image_or_video>
```
